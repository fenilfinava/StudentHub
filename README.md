# 🎓 StudentHub - CSPIT Charusat Student Portal

**StudentHub** is a comprehensive, fully functional frontend web portal designed for the students of **Computer Science & Engineering (CSE)** at **CSPIT, CHARUSAT University**. 

This project is built entirely using **Pure HTML5 Semantic Tags** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<details>`, `<meter>`, `<progress>`, etc.), demonstrating how to create a highly structured, accessible, and readable website without relying on external CSS frameworks or JavaScript dependencies.

## 📂 Project Structure & Features

The portal consists of **12 interconnected HTML pages**, covering every aspect of a university student's academic lifecycle:

### 1. Authentication & Onboarding
* `index.html` - The main landing page with campus overview, quick FAQs, and recent notices.
* `login.html` - Student and Faculty secure login portal using semantic forms and `<fieldset>`.
* `register.html` - Comprehensive new student admission and registration form.

### 2. Core Academic Dashboard
* `dashboard.html` - The central hub displaying overall attendance (`<meter>`), CGPA, upcoming tasks, and the complete Semester 3 timetable for CSE Division I (Room 506).
* `profile.html` - Student personal details, contact updates, and security settings using `<dl>`, `<dt>`, `<dd>` lists.

### 3. Academics & Performance
* `courses.html` - Detailed breakdown of enrolled Semester 3 subjects (FDSA, WDF, OOP, FCN, MATHS, HS) and interactive syllabus modules (`<details>` & `<summary>`).
* `attendance.html` - Subject-wise attendance breakdown showing precise percentages and a leave application form.
* `results.html` - Semester-wise SGPA history, overall CGPA tracking, and detailed marksheets using properly structured HTML tables (`<thead>`, `<tbody>`, `<tfoot>`).
* `assignments.html` - Assignment tracker and solution file upload portal.

### 4. Campus Life & Support
* `achievements.html` - Showcase of earned badges, verified certificates, and hackathon participation (e.g., Odoo Hackathon at LDCE).
* `notifications.html` - Official campus bulletins, examination alerts, and event updates using semantic `<article>` and `<time>` tags.
* `contact.html` - Important department helpdesk directory and an interactive online student inquiry form.

## 🚀 How to Run
1. Download or clone the repository to your local machine.

3. Open `index.html` in any modern web browser (Google Chrome, Firefox, Safari, Edge).
4. Use the navigation bar links to explore the entire portal seamlessly!
