Course Modules & Syllabus Outline

CSUC201 - Fundamentals of Data Structure and Algorithm (FDSA)

Study of linear and non-linear data structures including stacks, queues, linked lists, trees, graphs, and basic algorithmic complexities.


ITUE204 - Web Development Frameworks (WDF)

Advanced frontend and backend web technologies, semantic HTML5 structure, styling, responsive layouts, and Javascript frameworks.


CEUE203 - Object Oriented Programming (OOP)

Core object-oriented paradigms including classes, inheritance, polymorphism, encapsulation, abstraction, and file handling.


ITUC201 - Fundamentals of Computer Networks (FCN)

Computer networking models (OSI and TCP/IP), network protocols, routing algorithms, IP addressing, and transport layer security.


MSUD203 - Discrete Mathematics & HSUV201 - Creativity (HS)

Mathematical logic, set theory, combinatorics, and fostering creative engineering problem-solving approaches.
