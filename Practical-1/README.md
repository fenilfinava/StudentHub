---

### 📝 Problem Statement
Initiate the semester-long StudentHub portal by identifying the problem scope, user roles, key modules, navigation flow, and minimum 10 pages. Create a sitemap, low-fidelity wireframe, project folder structure, README file, and GitHub repository.

---

### 👥 User Roles
1. **Student:** Access dashboard, view timetable, attendance, marks, events, and manage profile.
2. **Faculty:** Manage courses, upload assignments, update attendance, and check results.
3. **Admin:** Manage users, system settings, and global announcements.

---

### 🗺️ Sitemap & Navigation Flow
- **Public:** Home ➔ Login | Register | Contact Us
- **Secured (Dashboard):** 
  - ➔ Profile (Manage details)
  - ➔ Courses (View syllabus)
  - ➔ Attendance (Check records)
  - ➔ Assignments (Submit work)
  - ➔ Results (Check grades)
  - ➔ Notifications (Campus alerts)
  - ➔ Directory (Search students/faculty)
